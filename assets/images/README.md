# Project images

This folder is reserved for The Tales of Babylon's own graphics: logos, banners, icons, and other images used in the repository's documentation. **No project images have been published yet.**

## Guidelines

- Add only original project artwork or images the project has permission to use. Third-party mod logos and other packs' assets do not belong here.
- Use lowercase file names with hyphens, for example `logo.png` or `banner.png`.
- Prefer PNG for logos and graphics with transparency, and keep files reasonably small.
- Reference images with relative paths, for example `assets/images/logo.png` from the README.

Gameplay screenshots belong in [`assets/screenshots/`](../screenshots/README.md).
