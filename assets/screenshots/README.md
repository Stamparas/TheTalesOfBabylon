# Screenshots

This folder is reserved for gameplay screenshots shown in the [preview gallery](../../docs/PREVIEW_IMAGES.md). **No screenshots have been published yet.**

## Guidelines

- Add only real, unedited in-game screenshots of The Tales of Babylon that reflect its actual state at the time they were taken.
- Use lowercase, descriptive file names with hyphens, for example `early-game-ore-processing.png`.
- Prefer PNG or JPEG, and keep files reasonably small.
- Give every screenshot a short caption in the preview gallery, including the pack version or development date it shows.

Logos, banners, and other graphics belong in [`assets/images/`](../images/README.md).
