# Reporting Issues and Contributing

The Tales of Babylon is under active development, and **there is not yet a public release**.

## Bug reports

Once a public build is available, please use the [bug report form](https://github.com/Stamparas/The Tales of Babylon/issues/new/choose) for reproducible problems affecting that build.

A useful report includes:
- the exact published The Tales of Babylon version and Minecraft/NeoForge version;
- concise reproduction steps and expected versus actual behavior;
- relevant error messages, crash reports or screenshots;
- whether the issue occurs in a clean, unmodified copy of the same release.

Before attaching logs, **remove passwords, tokens, personal data, and identifying local file paths**. Do not share private world or account data.

## Scope of the public issue tracker

Public issues should describe real defects, compatibility issues, or broken behavior in **published builds**. Duplicate reports should be consolidated. Experimental test results, private work notes, development-only benchmarks and internal planning are not tracked publicly.

## Feature requests and code contributions

The full contributor workflow is not open yet. Please do not assume that an undocumented experimental build is supported. Release packaging, versioning, contribution requirements and licensing will be documented before the first public release.

Minecraft and third-party mods remain subject to their own license terms and distribution permissions.
