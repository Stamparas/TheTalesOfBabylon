# Reporting Issues and Contributing

The Tales of Babylon is under active development, and **there is not yet a public release**. See the [README](README.md#development-status) for the current status.

## Before you report

- Check the [existing issues](https://github.com/Stamparas/TheTalesOfBabylon/issues) for a report of the same problem.
- Make sure the problem concerns a **published build** or **this repository's documentation**. Development-only builds and private tests are not supported.
- Remove private information from anything you attach (see [Logs and privacy](#logs-and-privacy)).

## Bug reports

Once a public build is available, please use the [bug report form](https://github.com/Stamparas/TheTalesOfBabylon/issues/new/choose) for reproducible problems affecting that build.

A useful report includes:
- the exact published The Tales of Babylon version and Minecraft/NeoForge version;
- concise reproduction steps and expected versus actual behavior;
- relevant error messages, crash reports or screenshots;
- whether the issue occurs in a clean, unmodified copy of the same release.

## Documentation corrections

If something in this repository is wrong, outdated or unclear, such as a broken link or an inaccurate statement in the README or the [development modlist](MODLIST.md), use the [documentation problem form](https://github.com/Stamparas/TheTalesOfBabylon/issues/new/choose). The modlist is a development inventory and changes during development; a mod being added or removed is not a documentation error.

## Logs and privacy

Before attaching logs, **remove passwords, tokens, personal data, and identifying local file paths**. Do not share private world or account data. For large logs, attach a file or provide a trustworthy paste link.

## Scope of the public issue tracker

Public issues should describe real defects, compatibility issues, or broken behavior in **published builds**, or errors in this repository's documentation. Duplicate reports should be consolidated. Experimental test results, private work notes, development-only benchmarks and internal planning are not tracked publicly.

## Feature requests and code contributions

The full contributor workflow is not open yet. Please do not assume that an undocumented experimental build is supported. Release packaging, versioning, contribution requirements and licensing will be documented before the first public release.

Minecraft and third-party mods remain subject to their own license terms and distribution permissions. See [Credits](docs/CREDITS.md).
