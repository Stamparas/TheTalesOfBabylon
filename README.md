## About

The Tales of Babylon aims to become a large, long-form expert modpack inspired by **Enigmatica 2: Expert**, **Divine Journey 2**, and **Dungeons, Dragons and Space Shuttles**. Its goal is an interconnected journey where engineering, magic, and exploration are all substantial parts of progression, rather than one being a small side activity.

The name evokes scale and mystery: an enormous journey with much to discover, not a historically accurate setting.

## Design pillars

These are the goals that guide development. They describe what the pack is being built toward, not finished features.

- **Technology and magic as equal foundations.** Both should have depth, distinctive mechanics, and meaningful connections across progression.
- **Exploration with a purpose.** Discoveries, structures, dimensions, and other adventures should matter to the wider experience.
- **Interconnected expert progression.** Recipes, production chains, and unlocks should reward understanding and combining different systems. Progression is planned as overlapping stages and interconnected branches rather than a single linear path.
- **Choices without shortcuts.** Where practical, multiple technologies or approaches should offer useful alternatives, while preserving a coherent overall challenge. Mandatory progression is kept distinct from optional improvements, alternatives, tutorials, and challenges.
- **Engineering over repetitive grinding.** The interesting work should be designing and improving resource processing, logistics, energy systems, and automation, not inflated recipe costs.
- **An extensive quest book.** Quests are intended to explain progression, teach systems, and guide a very large adventure without replacing the underlying gameplay.

## Development status

The modpack is being designed from a **clean slate**. Earlier experiments, mod selections, recipes, and progression plans serve as reference material; they are **not a finalized architecture**.

| | |
| --- | --- |
| **Minecraft** | 1.21.1 |
| **Mod loader** | NeoForge (the development instance currently uses NeoForge 21.1.265) |
| **Development modlist** | 540 mods, under evaluation ([MODLIST.md](MODLIST.md)) |
| **Quest book** | Not started; it follows the progression and recipe design |
| **Public release** | None yet |

The current platform is the development baseline, not a final decision. Mod availability, compatibility, progression chapters, recipe changes, and quest structure are subject to research, implementation, and testing. Any specific mod or feature discussed during development should not be treated as confirmed for a public release.

Development is proceeding from the early game. The first custom recipe work, an early-game ore-processing system, has been loaded and checked in a development instance; see the [changelog](CHANGELOG.md) for exactly what was verified.

The intended scope is ambitious, and the pack will only be presented as playable when its content and dependencies have been verified. This repository is currently a public information and issue-reporting hub, not a downloadable distribution.
